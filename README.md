# 📊 Stock Portfolio Tracker

A simple Python-based **Stock Portfolio Tracker** developed as part of the **CodeAlpha Python Programming Internship**.

The application allows users to enter stock names and quantities, calculates the investment value of each stock, displays the total portfolio value, and saves the portfolio details into a CSV file.

---

## 🎯 Project Objective

The main objective of this project is to build a simple stock portfolio tracker using Python.

The application demonstrates:

- Python dictionaries
- User input and output
- Basic arithmetic calculations
- Lists and dictionaries
- Functions
- Conditional statements
- Loops
- Error handling
- CSV file handling

---

## ✨ Features

- 📋 Displays a list of available stocks
- 💰 Uses predefined stock prices
- 📦 Allows users to enter stock quantities
- 🧮 Calculates individual stock investments
- 📊 Calculates total portfolio investment
- ✅ Validates stock symbols
- ✅ Validates quantity input
- 💾 Saves portfolio details to a CSV file
- 🖥️ Simple command-line interface
